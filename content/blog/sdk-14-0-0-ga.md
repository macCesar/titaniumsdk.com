## Install

**Follow these steps to get SDK 14.0.0.GA:**

1. Install the CLI with `npm i -g titanium alloy`
2. Run `titanium sdk install 14.0.0.GA`
3. Set `<sdk-version>14.0.0.GA</sdk-version>` in your `tiapp.xml`
